# Apple menu

An Omarchy menu with an Apple logo button for the bar (cloned from omarchy.menu).

Part of the [Liquid Glass theme for Omarchy](https://github.com/danluan/omarchy-liquid-glass-theme), but it can be used on its own.

## Install

```bash
omarchy plugin add https://github.com/danluan/apple-menu-plugin.git
omarchy plugin enable danluan.apple-menu --section left
```

Plugins run as unsandboxed code inside omarchy-shell: review the code before enabling it.
